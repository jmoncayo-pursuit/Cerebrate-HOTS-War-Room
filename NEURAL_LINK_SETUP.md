# 🧠 Neural Link (MCP) - Manual Setup Required

To enable the **Cerebrate Intelligence** to see through your eyes (the browser), you must manually grant permission at the OS/Browser level.

## 🚀 Execution Steps

1. **Enable Remote Debugging:**
   - Open a new tab in Chrome and navigate to: `chrome://inspect/#remote-debugging`
   - Toggle **"Allow remote debugging for this browser instance"** to **ON**.
   - Note the server address provided (usually `127.0.0.1:49375` or similar).

2. **Grant Connection Permission:**
   - When the Cerebrate server starts, Chrome will show a system dialog:
     > "Allow remote debugging for this browser instance?"
   - Click **Allow**.

3. **Verify the Link:**
   - Go to the **Tactical Services** panel in the War Room.
   - The **"Neural Link (Browser)"** status should switch to **STABLE**.
   - If it remains OFFLINE, ensure no other debugging sessions are active and refresh theWar Room page.
